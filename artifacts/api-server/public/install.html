← 🔥Working from Lenny

Install the MCP App

All 25 PM tools in one bundle, running locally inside Claude Desktop. No API key, no server, no data leaving your machine.

What you get

  • Every app from the site — quiz, wizard, generator, and rehearsal tools — available directly in chat
  • Corpus-grounded answers: tools pull from the same current-consensus knowledge base and flag anything that has recently changed
  • A home launcher (wfl_home) that lists every app with one-line descriptions and links to open each one
  • Local persistence for stateful tools (PM Ladder, Decision Log, Daily Dose streak) — your data stays on your machine

Requirements

  • Claude Desktop (Mac or Windows) — download here
  • Node.js 20 or later

Install

  1. Download the latest release.
    Go to github.com/sellisrev/working-from-Lenny/releases/latest and download working-from-lenny.mcpb.
  2. Open Claude Desktop.
    Go to Settings → MCP Apps (or press ⌘, on Mac).
  3. Drag in the file.
    Drag working-from-lenny.mcpb into the MCP Apps panel, or click the + button and select the file.
  4. Start a new conversation.
    Type show me what you can do or ask any PM question. Claude will call wfl_home to show the menu, or jump straight into whichever tool fits.
Prefer skills? Each app also runs as a Claude skill. Every tile on the home page carries a skill ↗ link. Skills work without installing the MCP App.
