# Atomic networks and network effects

## Current consensus

Anchored in Andrew Chen *The Cold Start Problem* + Lenny "The Atomic Network" (2021) + James Currier (NFX) framing.

### What an atomic network is
- **The smallest viable network unit** that demonstrates self-sustaining value.
- For Uber, one neighborhood with enough drivers + riders.
- For Slack, one team of 3+ active users.
- For Airbnb, one city with enough hosts and travelers.

### Why atomic networks matter
- **Cold-start problem solved one network at a time.** Cf. [marketplace-cold-start](marketplace-cold-start.md). Don't try to launch nationally; launch one atomic network at a time.
- **Atomic networks compound into broader networks.** Solving the first one teaches you how to solve the next.
- **Network effects (Helmer 7 Powers) emerge from atomic networks.** Aggregate network value depends on density per atomic unit.

### How to identify your atomic network
- **What's the smallest group where users get real value?**
- **What's the unit of density?** (Geography, team, school, profession.)
- **What share of that unit do you need to create value?** (Often 20-30%+; varies.)

### Common failure modes
- **Going broad too fast.** Pre-density expansion dilutes resources.
- **Wrong atomic network choice.** Picking the wrong unit (city vs. neighborhood; school vs. friend-group) wastes time.
- **Confusing initial users with atomic network.** A scattered set of early users isn't an atomic network.

### What's changed in 2025-2026
- **AI-mediated networks** are emerging (Mercor's eval marketplaces, AI-coding-agent communities). Atomic-network principle still applies.
- **Distribution-as-moat (Spiegel)** intersects: distribution into a specific atomic network can be the moat.

## What this means for non-PM consumers

- **If you're a marketplace / network founder**: pick your atomic network deliberately; commit to it.
- **If you're an investor evaluating a network/marketplace**: ask "what's the atomic network?" Vague answers are red flags.

## How thinking has evolved

- **2018-2022**: Andrew Chen / James Currier writings; Sarah Tavel hierarchy; corpus picks up vocabulary.
- **2022-2024**: Andrew Chen *Cold Start Problem* book + corpus marketplace canon.
- **2025-2026**: AI-mediated networks emerge; principle durable.
