# ChatGPT apps as distribution channel

## Current consensus

Anchored in Lenny "ChatGPT apps are about to be the next big distribution channel: Here's how to build one" (2026-04) + Nick Turley ("Inside ChatGPT", 2025-09).

### What ChatGPT apps are
- **Custom apps that run inside ChatGPT.** Distribution + execution + interaction model all live within the ChatGPT product surface.
- **A new platform layer**, analogous to App Store or Slack apps, but with conversational interface as the primary interaction.

### Why this matters as a distribution channel
- **Massive user base.** ChatGPT has hundreds of millions of users; reaching them through their default tool beats acquiring them separately.
- **Low friction.** Users don't install; they discover through conversation.
- **Conversational UI** offers a different demand pattern than traditional app stores.

### Lenny's "how to build one" framing
1. **Solve a frequent ChatGPT-user need.** What do users currently struggle with inside ChatGPT?
2. **Build the app simple.** Fewer features done well beats many features done poorly.
3. **Optimize for invocation.** Users have to ask the right thing to invoke your app; design for that.
4. **Track engagement.** Like any product surface, telemetry matters.

### Nick Turley's framing (Inside ChatGPT, OpenAI)
- **ChatGPT is moving toward platform.** App ecosystem is part of the strategy.
- **Distribution math is unprecedented**: ChatGPT user count + frequency = the largest single product audience in tech.
- **Product team operates with high velocity.** Cf. [ship-like-startup](ship-like-startup.md).

### Comparable parallel: MCP (Model Context Protocol)
- **Anthropic's MCP** is a similar platform layer for Claude. Different paradigm but same idea: apps that integrate into the AI assistant's context.
- **Multi-platform thinking** (ChatGPT + Claude + Google Gemini ecosystem) is increasingly necessary.

### What's changed in 2025-2026
- **The platform layer is now real.** What was speculation in 2024 is shipping in 2026.
- **Distribution-as-moat (Spiegel)** intersects with this — ChatGPT-app placement is a new distribution moat.
- **Cf. [ecosystem-channel](ecosystem-channel.md)**.

## What this means for non-PM consumers

- **If you're a CEO/founder**: ChatGPT apps + MCP integrations are distribution channels worth evaluating for 2026 strategy.
- **If you're a marketer**: discoverability inside ChatGPT is a new channel to learn.
- **If you're an investor**: products built primarily on ChatGPT-app distribution carry platform-dependency risk; ask about diversification.
