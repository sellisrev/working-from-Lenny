# Finding hidden growth opportunities in your product

## Current consensus

Anchored in Lenny "How to accelerate growth by focusing on the features you already have" (2024) + Albert Cheng ("How to find hidden growth opportunities in your product", 2025-12).

### The thesis
- **Most growth opportunities are inside the product, not outside it.** New acquisition channels are sexy; under-utilized features are usually higher leverage.
- **Existing features often hide unrealized engagement.** Users discover features over time; many don't, and engagement on those features is suppressed.
- **Activation work, not acquisition work**, is often the bottleneck. Cf. [activation-metric](activation-metric.md).

### Albert Cheng's pattern
- **Audit feature usage cohorts.** Which features have low engagement among users who'd benefit most?
- **Surface friction.** Discoverability and onboarding are usually the constraint, not feature missing.
- **Iterate on existing features instead of building new ones.** Smaller scope; higher reliable wins.

### Common patterns
- **Notification timing.** Users miss valuable interactions; better timing rescues engagement.
- **Onboarding into deep features.** Most products have power-user features hidden behind multi-step onboarding.
- **Cross-feature flows.** Users use feature A but never discover related feature B.
- **Reactivation of dormant users.** Existing users who churned are often easier to reactivate than new acquisitions.

### Common failure modes
- **Always building new.** "We need new features" framing dominates; existing features stay sub-optimal forever.
- **Surface-only optimizations.** UX polish without addressing underlying value-revelation problem.
- **Ignoring power-user signal.** Power users often reveal what mass users would benefit from.

### What's changed in 2025-2026
- **AI-personalization makes hidden-feature surfacing easier.** Models can predict which features each user would benefit from.
- **AI-augmented onboarding flows** can adapt to individual user context in real time.

## What this means for non-PM consumers

- **If you're a CEO**: ask the team "which features are under-utilized?" before approving new feature roadmap.
- **If you're a designer**: discoverability is design work. Audit existing features for it.
- **If you're an analyst / data scientist**: feature-usage cohort analysis is a high-leverage analysis to run.
