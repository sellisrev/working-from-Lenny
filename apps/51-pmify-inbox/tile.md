# Tile — #51 PM-ify My Inbox

> Lives on the landing page (advent-calendar / soundboard grid).

## Calendar door number

**Door 3.** Self-mocking PM-meta app; works best after a visitor has met door 1 (PM Pitfalls) and door 2 (PM Horoscope). The pure joke lands harder when the visitor has already seen the corpus is doing the work.

## 3–4 word hint

| Hint | Read |
|---|---|
| **Async unless urgent** | PM-jargon as the hint itself; the joke is in the wording. Visitors who recognize the phrase will click for the punchline; visitors who don't will wonder what's behind it. Either way it works. **Recommended.** |
| Mom asks, VP answers | More explicit setup; loses the deadpan. |
| Loop back next quarter | Same idea as "Async unless urgent"; slightly stiffer. |
| Capacity language ready | Same idea, less universal. |

## Link target

Tile click → `/pmify`. Paste box renders immediately, default mode is **pm-ify** (personal message → corporate-PM-speak). Toggle for **de-pm-ify** (work message → plain English) on the same page.
